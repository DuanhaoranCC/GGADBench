License texts not included in this directory must be obtained from the authors
before redistribution; citations alone do not grant permission to reuse code.

## TabPFN package and model weights

TFM4GAD uses the separately installed TabPFN package and can download a
TabPFN-v2 checkpoint. The upstream TFM4GAD README points to the
[Prior Labs license](https://priorlabs.ai/tabpfn-license/) for TabPFN weights.
No checkpoint, model license grant, or dataset license grant is included in
this release folder. Package code, copied source, model weights, and datasets
must each be used under their respective terms.
