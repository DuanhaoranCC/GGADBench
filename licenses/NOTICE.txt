# Third-party notices and source provenance

This benchmark contains adapted upstream implementations and implementations
written from research papers. The inventory below records evidence available
in the supplied source snapshots and source-code headers. It is not a statement
that every component has the same license. No project-wide license is assigned
by this document.

The four license files in `licenses/` are byte-for-byte copies of the supplied
upstream files, including their copyright names. A missing license text is
reported as missing; it is not permission to redistribute that component.
Before public distribution, the maintainer must resolve the missing upstream
license texts and applicable terms for copied or adapted code. A paper citation
alone does not establish a code license.

## TabPFN package and model weights

TFM4GAD uses the separately installed TabPFN package and can download a
TabPFN-v2 checkpoint. The supplied TFM4GAD README points to the
[Prior Labs license](https://priorlabs.ai/tabpfn-license/) for TabPFN weights.
No checkpoint, model license grant, or dataset license grant is included in
this release folder. Package code, copied source, model weights, and datasets
must each be used under their respective terms.
